# Calculadora em React Native 📱

Um aplicativo simples de calculadora desenvolvido como exercício prático, utilizando **React Native** com **Expo** e a biblioteca de componentes **React Native Paper**.

## 🎯 Objetivo
O objetivo principal deste projeto foi compreender o uso de componentes, frameworks visuais e Hooks (como o `useState`) dentro do ecossistema React Native.

## ✨ Funcionalidades
- Interface moderna e responsiva usando React Native Paper.
- Realiza as 4 operações matemáticas básicas: Adição (`+`), Subtração (`-`), Multiplicação (`*`) e Divisão (`/`).
- Botão **C** para limpar todo o display.
- Botão **DEL** para apagar o último caractere digitado.
- Exibição em tempo real da entrada e do resultado da operação.

## 🛠️ Tecnologias Utilizadas
- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [React Native Paper](https://reactnativepaper.com/) (UI Components)

## 🚀 Como Rodar o Projeto

1. Certifique-se de ter o Node.js instalado em sua máquina.
2. Clone este repositório:
   ```bash
   git clone https://github.com/arthurlockss/calculadora-rn.git
   ```
3. Acesse a pasta do projeto:
   ```bash
   cd calculadora-rn
   ```
4. Instale as dependências:
   ```bash
   npm install
   ```
5. Inicie o servidor do Expo:
   ```bash
   npx expo start
   ```
6. Você pode abrir o app pressionando `a` para Android, `i` para iOS (macOS), `w` para web ou escaneando o QR Code no app **Expo Go** do seu celular.
